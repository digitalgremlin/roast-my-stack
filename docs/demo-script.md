# Roast My Stack — demo script

Target runtime: 2:30.

## 0:00–0:20 — hook

“Paste a URL, get roasted. This is Dr. Gordon Pelican—please note the doctorate.
He detects the site’s real technology, judges its stack health, and turns the
verdict into fixes you can actually use.”

Show the one-page app and the five mood sprites.

## 0:20–1:05 — modern site

Paste `https://nextjs.org`.

While it runs: “The pipeline fetches the public page, applies a clean-room,
Codex-authored detector, and calculates a transparent score before GPT‑5.6 sees
anything.”

Show the Next.js/Vercel detections, score, impressed pelican, roast, and grounded
fixes. Point out that every fix names detected technology.

## 1:05–1:45 — roast-worthy site

Paste a WordPress site from the QA list.

“The same GPT‑5.6 call does the joke and the useful part. Tone scales with the
score, while the fixes lean toward patching, extension hygiene, and supported
runtimes. Dr. Pelican attacks technology choices, never people.”

Show the lower score, changed sprite, sharper roast, and security fixes.

## 1:45–2:05 — honest failure mode

Paste `https://httpbin.org/html`.

“If the detector has no evidence, it does not hallucinate. The app returns an
in-character ‘insufficient evidence’ verdict, with no invented fixes and no
model call.”

## 2:05–2:25 — share card

Open the result’s share link and show the generated PNG card.

“Each result gets a bounded, in-memory share ID and a server-rendered OG image:
score, verdict, and the mood-matched pelican.”

## 2:25–2:30 — close

“TypeScript, Apify Standby, GPT‑5.6, 120 original detection rules, and one
extremely credentialed bird. Roast My Stack.”
